# The World in One Day — Saturday 21 November 2026

A program that draws one front page summing up the world's news of Saturday 21 November 2026: 35 dated stories across 7 regions, as a single newspaper image.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes `out/entry.png` (1024×1024 PNG, deterministic, no network).
